# 🏏 IPL Analysis Dashboard | Power BI

## 📊 Project Overview

This project is an interactive IPL Analysis Dashboard developed using Microsoft Power BI.

The dashboard analyzes IPL data from **2008 to 2025** and provides interactive insights into team performance, player performance, batting statistics, bowling statistics, match results, and season-wise IPL trends.

The dashboard is designed to transform raw IPL data into meaningful and easy-to-understand visual insights using **Power Query, Data Modeling, and DAX**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze IPL performance from 2008 to 2025.
- Analyze season-wise team performance.
- Identify the Champion and Runner-up team.
- Analyze Orange Cap and Purple Cap performers.
- Analyze top batsmen based on runs, fours, and sixes.
- Analyze top bowlers based on wickets.
- Compare matches played, won, lost, tied, and no-result matches.
- Analyze centuries and half-centuries.
- Analyze venue-wise IPL statistics.
- Create an interactive and user-friendly Power BI dashboard.
